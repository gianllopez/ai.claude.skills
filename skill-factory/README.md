# Skill Factory

The authoring toolkit for this skills collection. It standardizes how new skills are structured so that complexity, organization, and maintainability stay under control as the collection grows.

## Structure

- `SKILL.md` - The whole standard: tier selection, authoring workflow, file formats, and the `AGENTS.md` compilation procedure
- `metadata.json` - Skill metadata (version, author, abstract, reference links)
- `templates/` - Copy-ready starting points
  - `tier-1/` - Minimal skill (`SKILL.md` only)
  - `tier-2/` - Procedural skill (`SKILL.md` + `metadata.json` + `README.md`)
  - `tier-3/` - Compiled skill (Tier 2 + `rules/` + generated `AGENTS.md`)

## The three tiers at a glance

| Tier           | Structure                                               | For                            |
| -------------- | ------------------------------------------------------- | ------------------------------ |
| 1 · Minimal    | `SKILL.md`                                              | A single stable instruction    |
| 2 · Procedural | `SKILL.md`, `metadata.json`, `README.md` (+ `scripts/`) | A workflow or tool integration |
| 3 · Compiled   | _Tier 2_ + `rules/` + generated `AGENTS.md`             | A large, evolving rule catalog |

## Usage

1. Read `SKILL.md` and pick a tier
2. Copy `templates/tier-<n>/` into `~/.claude/skills/<skill-name>/`
3. Replace every placeholder and validate with the checklists in `SKILL.md`
4. For _Tier 3_, author the rules and compile `AGENTS.md` per the procedure in `SKILL.md`

## Design principles

- Only `SKILL.md` is required by the official spec; the rest is convention layered by complexity
- Everything lives in `SKILL.md`. A skill's instructions are never split across side documents; when the body outgrows one coherent procedure it becomes a _Tier-3_ rule catalog, not a folder of extra guides
- One source of truth. Generated artifacts (`AGENTS.md`) are never hand-edited
- No bundled commands. Content skills ship no build script; `AGENTS.md` is regenerated by following the described procedure in `SKILL.md`
